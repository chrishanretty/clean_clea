# cleaclean 0.1.0

* Converted the repository into an installable R data package.
* Added the `clean_clea` and `simple_systems` package datasets.
* Added a reproducible, audited maintainer build workflow and explicit tests.
* Applied the current Swedish election magnitude and seat corrections. Relative
  to the previously committed processed dataset, these corrections change both
  `mag` and `seat` on 359 rows (718 cells total), exclusively in election IDs
  584 and 585.
