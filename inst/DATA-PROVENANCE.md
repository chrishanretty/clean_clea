# Data provenance and terms

The installed datasets are derived from the Constituency-Level Elections
Archive (CLEA), with documented corrections and additions from the sources
cited in the package repository.

The raw CLEA distribution is not included in the package or repository. The
MIT licence applies to package code only. It does not independently relicense
the derived datasets or supersede terms attached to CLEA, V-Dem, or other
underlying sources.

Use `citation("cleaclean")` for package and source citations. See
<https://github.com/jackobailey/clean_clea> for the full cleaning methodology,
auditable correction scripts, exclusions, known limitations, and source
manifest.
